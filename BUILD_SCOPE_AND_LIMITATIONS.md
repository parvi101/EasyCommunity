# Build Scope and Limitations

This v0.1.0 package is a **working controlled MVP**. It is suitable for local demonstration, requirements validation and Council/UAT review. It is not yet suitable for public production use.

## Implemented
- Separate product application and database
- Mobile-first installable PWA
- Product-specific core workflow
- Health/freshness state
- Decision and audit evidence
- Automated API tests and smoke-test evidence
- Left/right single-hand preference where relevant

## Production gates still open
- Production identity, authorisation and tenant isolation
- HTTPS, hardened secrets, security testing and incident response
- PostgreSQL and formal migration/rollback
- Formal WCAG 2.2 AA and representative-user validation
- Cloud or venue deployment architecture
- External live-event/source integrations
- Native Android/iOS packaging
- Backup, recovery, support and SLA evidence
- Patent-professional review before public disclosure of novel mechanisms
