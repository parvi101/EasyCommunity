# EasyCommunity v0.1.1 Controlled MVP

## Run on Windows
1. Install Python 3.11 or later.
2. Extract this package into its own folder.
3. Double-click `INSTALL_AND_RUN_EasyCommunity.bat`.
4. Open `http://127.0.0.1:8781`. Admin: `http://127.0.0.1:8781/admin`.

The product-specific installer name makes it easy to distinguish from ParkEasy and Project Phoenix installers.

The PWA can be installed from a supported browser. This is a local controlled MVP, not a public production release.
