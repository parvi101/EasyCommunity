# Accessibility and Human Factors

- Responsive mobile-first layout
- Left-hand and right-hand single-hand modes
- Large touch targets and high-contrast controls
- Text labels alongside essential actions
- Keyboard-operable desktop controls
- No information conveyed by colour alone
- Clear actual/estimated/forecast and live/stale labels
- Plain-language warnings without false urgency
- No dark patterns or forced engagement

Formal WCAG 2.2 AA, screen-reader and representative-user testing remain release gates before production.
