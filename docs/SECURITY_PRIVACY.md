# Security and Privacy Baseline

This is a local controlled MVP and does **not** include production authentication, TLS termination, hardened secrets management, rate limiting or formal penetration testing. Before any public or live-personal-data pilot, implement role-based identity, HTTPS, secure session management, encryption, privacy notices, retention/deletion workflows, security testing and incident response.

The mobile/PWA security checklist is aligned conceptually with OWASP MASVS categories: storage, cryptography, authentication, network, platform interaction, code quality and resilience.
